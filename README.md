# Weather App
A simple weather app built using HTML, CSS, and JavaScript that fetches real-time weather data using an API.

## Features
- Search weather by city
- Toggle between Celsius and Fahrenheit
- Dark mode support
- Responsive design

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/v1sh999/Weather-Update.git
2. Open repo with VScode
3. run a live server

## Usage

- Enter a city name in the search bar
- Click the search button
- View weather details instantly
